# LL Test

Проект создан для студии Last Level в качестве тестового задания на позицию Tech UI.

Репозиторий содержит исходный Unity-проект: код, сцены, интерфейсы, конфигурации, локализацию и графические ассеты.

## Запуск

1. Установите Unity `2022.3.62f2` через Unity Hub.
2. Скачайте `LL-Test-main-latest.zip` из prerelease **Latest main project archive** на странице GitHub Releases.
3. Полностью распакуйте архив.
4. В Unity Hub выберите **Add project from disk** и укажите распакованную папку `LL-Test`.
5. Дождитесь восстановления пакетов, импорта ассетов и завершения компиляции.
6. Откройте сцену `Assets/_Project/Scenes/Bootstrap.unity` и запустите Play Mode.

При первом открытии потребуется доступ в интернет. Восстановление зависимостей и импорт ассетов могут занять
несколько минут.

## Архивы

После каждого обновления ветки `main` GitHub Actions создаёт и проверяет новый архив проекта. Актуальная версия
публикуется в prerelease `main-latest`, а архивы отдельных запусков хранятся в GitHub Actions 90 дней.

Контрольная сумма находится в приложенном файле `.sha256`. Точный commit и время создания указаны внутри архива
в `BUILD-INFO.txt`.
